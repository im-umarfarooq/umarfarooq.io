# Umar Farooq — Portfolio

A dark, professional portfolio site with a 3D animated skill orbit, built with
plain HTML, CSS, and JavaScript (no frameworks, no build step).

## Files
- `index.html` — page content and structure
- `style.css` — all styling, including the 3D orbit animation
- `script.js` — nav toggle, floating CTA visibility, contact form validation
- `assets/resume.pdf` — **add your own resume PDF here** (referenced by the Download Resume button)

## Before you publish
Search the files for these placeholders and replace them with your real info:
- `your.email@example.com`
- `github.com/your-username` and `linkedin.com/in/your-username`
- `Your City, Country`
- The "X+" stats in the stats bar
- The 3 project cards (real names, screenshots/thumbnails, links, and results)
- The About photo placeholder — swap `.about__photo` for a real `<img>`

## Deploy on GitHub Pages
1. Create a new repository on GitHub (name it `your-username.github.io` if you
   want your portfolio at that exact URL, or any name if you're fine with a
   `/repo-name` path).
2. Add all files in this folder to the repo (keep the same file names/paths).
3. Commit and push to the `main` branch.
4. In the repo, go to **Settings → Pages**.
5. Under "Build and deployment", set Source to **Deploy from a branch**, pick
   `main` and `/ (root)`, then Save.
6. Your site will be live at the URL GitHub shows (usually within a minute or two).

## Connecting the contact form
GitHub Pages only serves static files, so the form currently validates input
but doesn't send email. To receive real submissions, sign up for a free plan
on [Formspree](https://formspree.io) or [EmailJS](https://www.emailjs.com) and
follow their few-line setup — both work without a backend.
